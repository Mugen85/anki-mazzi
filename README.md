## 💡 Perché questo mazzo?

La memoria umana è come un motore: **se non la fai girare, si ingolfa.**

Questo mazzo utilizza la **Spaced Repetition (Ripetizione Dilazionata)** per aiutare a fissare i concetti di programmazione nella memoria a lungo termine.

È nato da un'esigenza reale: studiare e consolidare concetti di programmazione e architettura software nei ritagli di tempo, magari in officina tra il montaggio di un carter e un cambio olio, oppure durante una pausa in un viaggio in moto con la mia XT1200Z.

L'obiettivo non è accumulare teoria.

È **ricordare ciò che serve per scrivere software migliore**, un concetto alla volta.

Niente fronzoli.
Niente teoria fine a sé stessa.
**Fondamenti, pratica e architettura.**

## 📱 Mobile-First — Zero Scroll Orizzontale

Il mazzo è stato progettato pensando anche allo **studio da smartphone**.

Gli snippet di codice utilizzano una formattazione CSS specifica:

```css
white-space: pre-wrap;
word-wrap: break-word;
```

L'obiettivo è evitare il fastidioso **scroll orizzontale** durante la lettura del codice.

Puoi quindi ripassare le carte anche dal telefono, con una mano sola, durante una pausa al lavoro, sul divano o prima di iniziare un viaggio.

## 📥 Come usarlo

### Opzione 1 — Il metodo più veloce (.apkg)

1. Scarica [Anki](https://apps.ankiweb.net) su PC oppure [AnkiDroid](https://play.google.com/store/apps/details?id=com.ichi2.anki) su Android.
2. Scarica il file `.apkg` dalla sezione [Releases](https://github.com/Mugen85/anki-mazzi/releases).
3. Fai doppio clic sul file scaricato: Anki lo importerà automaticamente.
4. Sincronizza il tuo account Anki per avere le carte anche sugli altri dispositivi.
5. Dedica anche solo **10 minuti al giorno** al ripasso.

> La costanza conta più della quantità.

---

### Opzione 2 — Importazione manuale per sviluppatori

Se vuoi modificare o personalizzare le carte:

1. Scarica i file `.csv` presenti nella cartella sorgente.
2. Apri **Anki → File → Importa**.
3. Seleziona il file `.csv`.
4. Imposta il **punto e virgola (`;`)** come separatore.
5. Attiva **"Consenti HTML nei campi"** per visualizzare correttamente la formattazione e gli snippet di codice.
